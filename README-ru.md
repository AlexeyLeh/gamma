# Калибровка гамма-детектора

Работает с БТО и com-портом.

### Загрузка данных последнего теста

Предусмотрена возможность воспроизвести данные последнего теста.



### Симуляция

Есть режим симуляции, при котором можно проверить работу алгоритмов в тестах линейности и API.

Активируется в ini-файле.

```
[General]
Simulation=true
```

В меню "Файл" появятся два пункта:

* Загрузить симуляцию
* Сохранить симуляцию


В тесте линейности появится кнопка "Выбор симуляции".
Выбранный файл будет загружен и будут отображены графики и данные теста.
Пример файлов симуляции находится в папке Simulations.

При отсутствии папки Simulation образец файла можно создать воспользовавшись пунктом "Сохранить симуляцию".
Будет сохранены тестовые данные, "прошитые" в программе.
Далее файл может быть отредактирован под нужные данные любым тестовым редактором.

### Нумерация файлов:

gamma-bto-3.2.2-bin-win11-64-20260914-1145.7z

* gamma_bto - версия работы с БТО и com-портом - выбор в настроках
* версия    - 3.2.2
* bin       - комплект запуска
* src       - исходники (qt-проект)
* сборка    - win7-32 или win11-64
* далее     - дата-время сборки
